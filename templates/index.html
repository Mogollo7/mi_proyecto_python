Descripción del proyecto

Qué es este proyecto

Naturaleza & Experiencia Web es una página web construida con Python y Flask, con una interfaz de un solo módulo (HTML5 + CSS3 puro, sin frameworks de frontend) servida mediante plantillas Jinja2.

Objetivo

Presentar el proyecto y documentar su evolución técnica

El objetivo de esta página es presentar el proyecto y explicar, de forma visual y accesible, la arquitectura del sistema: su stack, la función de cada tecnología y la organización en capas. El despliegue y la estructura de carpetas del repositorio están documentados en el README.md del proyecto.

Arquitectura del sistema

Cómo está organizado, conceptualmente

Antes del diagrama, dos ideas de teoría de software necesarias para leerlo: una arquitectura cliente-servidor separa quien pide datos (cliente/frontend) de quien los procesa (servidor/backend); una API (interfaz de programación de aplicaciones) es el contrato mediante el cual esas dos partes se comunican, típicamente sobre HTTP siguiendo el estilo REST. El siguiente diagrama representa la arquitectura de Naturaleza & Experiencia Web bajo esos principios.

Stack tecnológico

Tecnologías y su función

Este es el stack tecnológico que presenta Naturaleza & Experiencia Web y la función que cumple cada pieza dentro de la arquitectura del sistema.

Python

Lenguaje de programación interpretado y de propósito general: es el lenguaje del backend de este sitio (app.py) y de los servicios que conforman la arquitectura.

Flask

Microframework de Python sobre el protocolo WSGI (síncrono): un núcleo mínimo al que se añaden solo las piezas necesarias. Sirve esta página mediante render_template, usando el motor de plantillas Jinja2.

FastAPI

Framework de Python sobre ASGI (asíncrono) para construir la API y los servicios backend: usa anotaciones de tipos para validar datos automáticamente y genera documentación interactiva (OpenAPI) por sí mismo.

Vite

Herramienta de desarrollo y construcción para el frontend, con recarga instantánea (HMR) y empaquetado optimizado.

PostgreSQL

Sistema de gestión de base de datos relacional (RDBMS) que persiste la información de los servicios, usando SQL y garantías ACID.

Microservicios

Forma de organizar el software en la que las responsabilidades del sistema se dividen en servicios independientes, desplegables y escalables por separado, en contraste con una aplicación monolítica.

Render

Plataforma de despliegue en la nube (PaaS) usada para publicar este sitio. El detalle del despliegue está documentado en el README.md.

HTML5, CSS3 & SVG

Interfaz de esta página: marcado semántico, variables CSS, Flexbox/Grid y gráficos vectoriales SVG, sin frameworks de frontend.
